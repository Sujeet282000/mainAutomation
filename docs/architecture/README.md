# Architecture

This directory contains the active architecture and implementation documentation for the automation platform.

## Active documents

- `target-architecture.md` — canonical runtime/service boundaries.
- `implementation-status.md` — migration checklist and verification status.

## Research

Historical product research belongs under `docs/research/` and is not runtime configuration.

## Rule

Documentation must describe the current implementation or an explicitly planned migration. Generated trees, temporary diffs, logs, IDE/worktree artifacts and copied research dumps do not belong in the repository root.
