# API Surface Map

Generated by `node tools/api-audit.mjs` (diffs backend route registrations against web-app calls).
**Every route the web app calls resolves to a handler — zero breakage** (verified by the E2E smoke test
and the auth-e2e suite against the running API).

## Primary surface (consumed by apps/web)

| Family | Endpoints | Notes |
| --- | --- | --- |
| Auth | `POST /auth/register`, `POST /auth/login`, `GET /me` | JWT; workspace via `x-workspace-id` |
| Automations | `GET/POST /automations`, `GET/PUT/PATCH/DELETE /automations/:id`, `POST /automations/:id/{run,publish,validate,test-step,duplicate}` | Builder contract; publish returns `webhookUrl` + activates triggers |
| Executions | `GET /executions`, `GET /executions/:id`, `/executions/:id/stream` (SSE), `/executions/:id/retry` | Step rows joined server-side on the partition key |
| Analytics | `GET /analytics/summary?days=N` | Postgres-side aggregates: daily series, trigger mix, slowest steps, failure messages, latency p50/p95/p99 |
| Connections | `GET/POST /connections`, `PATCH/DELETE /connections/:id`, `POST /connections/:id/test` | Test runs the per-vendor verifier (`catalog/connection-testers.ts`) |
| OAuth | `GET /oauth/connection-setup/:app`, `GET /oauth/:provider/start`, `GET /oauth/:provider/callback`, Google/Slack legacy routes | Registry-driven (28 providers, `catalog/oauth-providers.ts`) |
| Catalog | `GET /apps`, `GET /apps/:slug`, `GET /templates`, `POST /templates/:id/use`, `GET /oauth/apps` | 164-app directory |
| Builder AI | `POST /copilot/sessions`, `/copilot/sessions/:id/{stream-chat,refine,approve,persist,generate}`, `POST /chat` (SSE) | Python plane first, Node cascade fallback |
| Data | `GET/POST /tables`, `/tables/:id/records(+:recordId)`, `GET/POST /forms`, `/forms/:id/submissions` | Tables & forms |
| Agents | `GET/POST /agents`, `/agents/:id`, `/agents/:id/run`, `/agents/:id/activities`, `/agent-approvals/:id/decide` | Runtime cascades all model providers |
| Product surface | `/chatbots(+:id/chat)`, `/canvases`, `/interfaces`, `/developer-apps`, `/transfers`, `/email-parsers`, `/webhook-events` | `modules/products.ts` + fallback router |
| Misc | `/billing`, `/usage`, `/audit`, `/notifications(+/:id/read)`, `/knowledge`, `/folders`, `/variables`, `/api-keys`, `/mcp/tokens`, `/health` | All live |

## Machine / non-UI surfaces (intentionally not called by the web app)

- `POST /v1/webhooks/inbound/:token` — trigger ingress (called by external vendors)
- `POST /sdk/run` — server-side SDK entry
- `/internal/*` — worker/scheduler control plane
- `/public/forms|chatbots|interfaces/*` — anonymous share-link surfaces

## Legacy compatibility surface (kept, documented — do not delete)

These are older/parallel families still served for compatibility with earlier clients and the
compat router (`ui-compat.ts`). They are exercised by tests, not the current web app:

- `/flows*` (list/get/patch/delete/publish/activate/deactivate/validate/step-test) — pre-"automations" naming; `/flows/:id/publish` remains the canonical reference implementation that `/automations/:id/publish` mirrors
- `/runs*` (list/detail/stream/content) — pre-"executions" naming
- `/table-assets*` — pre-"tables" naming
- `/copilot/build|generate|refine|diagnose-run|explain-field|suggest-*|test-step|fixtures|readiness|status` — stateless copilot v1; sessions API supersedes it
- `/ai/*` (`copilot`, `copilot/chat`, `copilot/accept`, `settings`) — legacy alias layer
- `/connection-setup/:app`, `/connections/setup/:app` — older names of `/oauth/connection-setup/:app`
- `/todos`, `/todos/:id/resolve`, `/approvals/:id/decide` — pre-"agent-approvals" approval flow
- `/assets*`, `/storage`, `/meta`, `/catalog`, `/pieces`, `/pieces/search`, `/organization*`, `/workspaces` — earlier workspace model endpoints

**Pruning rule:** delete a legacy family only after `node tools/api-audit.mjs` shows it uncalled AND
`grep` confirms no API consumer (worker, scheduler, Python plane, docs, SDK) references it. The
Python AI plane calls the Node API via `apps/ai/orchestra_ai/node/client.py` — always grep that too.
